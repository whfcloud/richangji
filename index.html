添加到桌面

像 App 一样打开

iPhone / iPad：请用 Safari 打开
  1. 点底部中间的「分享」按钮（方框加向上箭头）
  2. 在列表里下滑，找到「添加到主屏幕」
  3. 点右上角「添加」，桌面就会出现「日常集」图标

注意：iPhone 上必须用 Safari，微信/QQ/Chrome 里打开是找不到这个选项的。

安卓（Chrome / Edge / 夸克等）
  1. 点右上角「⋮」菜单
  2. 选「添加到主屏幕」或「安装应用」
  3. 确认后桌面出现图标，点开就是全屏 App
电脑（Chrome / Edge）
  1. 点地址栏右侧的「安装」小图标（显示器加向下箭头）
  2. 或在菜单 →「投放、保存和共享」→「安装页面为应用」

如果菜单里还是没有这项：先刷新一次页面（新装的能力需要刷新后才被浏览器识别），再回到菜单看看。

添加后打开就是全屏 App 体验，不带浏览器地址栏，数据照常自动同步。

换手机 / 换电脑怎么办？连接配置只存在当前浏览器里，新设备需要再填一次。点下面的按钮生成一个「手机端配置链接」，在手机上打开即可自动完成配置，然后登录同一个账号就能看到同一份数据。
零成本备选。数据存成一个 GitHub Gist 文件，只要有 GitHub 账号就能用。
  1. 到 github.com/settings/tokens 生成 token，只勾选 gist 权限
  2. 到 gist.github.com 新建一个 secret gist，从地址栏复制它的 ID
在 Supabase 的 SQL Editor 里整段执行一次即可。建好后每张表都带 user_id 并开启行级安全，只有你登录后才能读写自己的数据 —— anon key 公开也无妨，未登录的人什么都拿不到。 建好后你也可以在 Supabase 后台直接查看和编辑这些数据。
